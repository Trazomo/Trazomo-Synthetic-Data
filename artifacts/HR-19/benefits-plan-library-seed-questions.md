# Benefits Plan Library: Seed Question Set

This file is not a library document. It carries no document identifier, it is not in the benefits plan register, and nothing in it describes a plan. It is the seed question set that a knowledge base built over the benefits plan library is evaluated against: ten questions of the kind employees put to People Operations, each with the outcome the knowledge base is expected to reach. The table has one row per question and seven columns. Question ID runs BSQ-01 upward. Language is the language the question is asked in, and English gloss gives an English rendering of any question not asked in English. Expected outcome is one of two values: answer, where the knowledge base answers from the library, or refuse_and_route, where it declines to answer and sends the question to the person named in Route to. Answer sources names the library documents an answer must draw on, by document id only and never by section, separated by a semicolon; it states where an answer is found and never what the answer is. Fields that do not apply read None.
